# VPN setup — remote access for staff

_Space: IT-SD · Owner: Marta Nowak · Last edited: 2024-11-02_

## Who gets VPN

Office staff, IT/OT, quality and planning. Production operators do not get VPN. Access is requested
through NordDesk as an access request with the line manager's approval attached.

## Setting up the client

1. Install **GlobalProtect** from the software portal on your laptop.
2. Portal address: `vpn.nordfarm.local`
3. Sign in with your normal Windows username and password.
4. When asked for the second factor, type the 6-digit code from your **hardware token** (the small
   grey key fob issued by the servicedesk).
5. You are connected when the shield icon turns blue.

## Troubleshooting

- "Portal not reachable": check you are not on the plant Wi-Fi — VPN is for outside the plant.
- Token code rejected three times: the token may have drifted; bring it to the servicedesk.
- Slow file access: use the mapped drive, not the web client.
